# MassQL Compendium for Psychoactive Tryptamines

This repository contains analysis scripts, processing workflows, and supplementary data associated with our manuscript "A Hierarchical MassQL Compendium for Annotating Psychoactive Tryptamines and Their Analogs in Untargeted Metabolomics".

## Repository Contents

### Figures
Python scripts and input data used to generate the figures presented in the manuscript.

### Data_processing_MZmine
MZmine batch files and processing parameters used for LC-MS/MS data processing.

### Supplementary_Tables
Supplementary tables, including the curated inventory of psychoactive tryptamines, the MassQL query compendium, and associated analytical results.

### MassQL Results Manipulation
Scripts and workflows used to organize, filter, and analyze MassQL retrieval results, including the consolidation of query matches and prioritization of spectral features satisfying multiple fragmentation criteria.

## Data Availability

The publicly available forensic LC-MS/MS dataset analyzed in this study is accessible through the GNPS/MassIVE repository under accession number [MSV000086280](https://massive.ucsd.edu/ProteoSAFe/dataset.jsp?task=MSV000086280).
